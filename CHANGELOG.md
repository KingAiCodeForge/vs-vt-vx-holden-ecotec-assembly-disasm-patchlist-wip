# Changelog

## 0.1.0-alpha.1 — 2026-10-20

Promotes one generic first-party local metadata helper after preservation,
source/data review and synthetic tests. The `holden-bin-diff` CLI compares
read-only inputs, bounds file/report sizes, omits paths and byte previews by
default, rejects invalid hashes/sizes before report publication, and refuses
input/output aliases and all existing outputs. No checksum repair or patch
generation is included. Adds installable packaging and actionable diagnostics.

Adds a per-file intake ledger, a source promotion contract and six distinct
target records transcribed from the public README. Three other inspected local
helpers remain held; 71 local source candidates remain individually unreviewed
and are excluded from the release. Ignore exceptions admit only reviewed files.

No firmware, disassembly, patch, flash artifact or hardware qualification is
part of this alpha release. It does not establish VS/VT/VX/VY bank mappings.
